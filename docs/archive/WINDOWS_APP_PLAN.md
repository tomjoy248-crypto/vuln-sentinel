# Vuln Sentinel Windows 版落地清单 ## 推荐方案 优先用 **Tauri** 作为 Windows 壳：- 复用现有 Web 前端
- 安装包更轻
- 启动更快
- 更适合后续做自动更新 ## 第一版目标 - 把现有 Web 版打包成 Windows 可安装程序
- 保留登录、扫描、结果、套餐、审计、报告功能
- 支持本地浏览器外壳启动
- 保持与 Web 版同一账号体系和套餐体系 ## 第一阶段要做的事 1. 选择壳技术：Tauri 或 Electron
2. 把 Web 前端接入桌面容器
3. 配置本地 API 地址和环境切换
4. 增加应用图标、名称、版本号
5. 打包 Windows 安装程序
6. 增加自动更新和崩溃恢复 ## 最小可交付版本 - 登录页可用
- 扫描页可用
- 结果页可用
- 套餐页可用
- 支持桌面启动
- 可安装、可卸载、可升级 ## 后续增强 - 系统托盘
- 开机启动
- 通知中心
- 离线缓存
- 本地配置导入导出
- 企业签名与安装包分发 ## 当前结论 现在最适合先做 Web 商业版，再把同一套前端包进 Windows 壳，而不是重新写一套原生界面。
