# Web 交付边界

## 已经可以对外说明的能力

- 输入网址后开始扫描
- 扫描结果可查看、可导出、可复扫
- 结果会区分已验证、可能存在、待人工复核
- 套餐、积分、购买记录、审计留痕可用
- PWA 安装引导已存在

## 目前仍然要谨慎说明的部分

- 更深层漏洞覆盖还在扩展
- 误报控制还在持续优化，尤其是通用错误页、软 404、CDN/WAF 干扰场景
- Windows 桌面壳已可交付，但仍建议继续做真实安装回测
- 企业级自动更新和签名还未完成

## 对外话术建议

- 这是一个可收费的 Web 安全交付产品
- 适合试用、项目交付和小团队使用
- 结果会明确标注“已验证 / 可能存在 / 待复核”
- 不承诺“扫全、扫准、扫深”，强调证据与复核
