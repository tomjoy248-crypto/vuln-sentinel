# Vuln Sentinel Windows 交付验收清单

## 文档目的

本文档用于 Windows 桌面版上线前的最终验收，覆盖安装、启动、扫描、PDF 报告与卸载流程。

## 验收范围

- Windows 桌面安装包
- 桌面快捷方式与开始菜单入口
- 登录页、首页、扫描页、结果页
- PDF 报告导出
- 卸载与残留清理

## 验收前提

- 已获取安装包 `artifacts/windows/Vuln-Sentinel-11.0.0-win64-setup.exe`
- 已准备至少一个授权扫描目标
- 验收机器为普通 Windows 用户权限
- 验收时可访问本地或授权目标站点

## 验收步骤

1. 安装桌面版。
2. 确认安装目录创建成功。
3. 确认桌面快捷方式和开始菜单入口存在。
4. 启动应用并确认登录页正常打开。
5. 进入首页并确认扫描入口正常显示。
6. 输入授权目标并开始扫描。
7. 确认结果页能展示评分、风险等级、证据、修复建议与工单入口。
8. 导出 PDF 报告并确认可下载。
9. 打开 PDF，确认中文显示正常，且包含客户摘要、风险概览、发现项与建议。
10. 执行卸载。
11. 确认应用目录、快捷方式和开始菜单入口被清理。
12. 卸载后再次尝试打开入口，确认无残留异常。

## 验收判定

- 安装、启动、扫描、导出、卸载均无异常
- PDF 可正常下载，且内容完整、中文正常
- 卸载后无明显残留入口
- 结果页可直接作为客户沟通与交付材料

## 建议补充项

- 多次安装/卸载循环
- 不同 Windows 账户权限下的安装验证
- 断网状态下的启动与恢复验证
- 大报告体量下的 PDF 导出验证
