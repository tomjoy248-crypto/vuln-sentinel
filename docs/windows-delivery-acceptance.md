# Vuln Sentinel Windows 交付验收清单

## 文档目的

本文档用于 Windows 桌面版上线前的最终验收，覆盖安装、启动、扫描、PDF 报告与卸载流程。

- 版本：11.0.0
- 适用包：`Vuln-Sentinel-11.0.0-win64-setup.exe`
- 验收结论：可安装、可启动、可扫描、可导出、可卸载

## 验收范围

- Windows 桌面安装包
- 桌面快捷方式与开始菜单入口
- 登录页、首页、扫描页、结果页
- PDF 报告导出
- 卸载与残留清理

## 验收前提

- 已获取安装包 `artifacts/windows/Vuln-Sentinel-11.0.0-win64-setup.exe`
- 已准备至少一个授权扫描目标
- 验收机器为普通 Windows 用户权限
- 验收时可访问本地或授权目标站点

## 验收判定

- 安装、启动、扫描、导出、卸载均无异常
- PDF 可正常下载，且内容完整、中文正常
- 卸载后无明显残留入口
- 结果页可直接作为客户沟通与交付材料
- 客户摘要、交付结论和后续动作可直接归档

## 建议补充项

- 多次安装/卸载循环
- 不同 Windows 账户权限下的安装验证
- 断网状态下的启动与恢复验证
- 大报告体量下的 PDF 导出验证

## 重点检查

- 安装路径是否落在当前用户目录，避免权限问题。
- 桌面和开始菜单入口是否都存在且可启动。
- 首次启动后，首页、扫描页和结果页是否无空白或报错。
- 扫描结果是否能直接说明风险、证据和修复建议。
- PDF 是否包含客户摘要、结论和后续动作。
- 卸载后是否无残留目录、快捷方式或异常入口。

## 失败判定

只要出现以下任一情况，即判定为本轮验收失败：

- 无法完成安装或启动。
- 扫描按钮不可用或结果页无法生成。
- PDF 无法下载、乱码、缺失客户摘要或关键结论。
- 卸载后仍保留程序目录、快捷方式或开始菜单入口。
