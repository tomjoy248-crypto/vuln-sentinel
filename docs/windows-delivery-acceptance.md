# Vuln Sentinel Windows 一页验收清单

## 基本信息
- 版本：以 Releases 页最新版本为准
- 安装包：以 Releases 页展示的最新安装包为准
- 验收目标：确认 Windows 桌面版安装后能正常打开托管页面，并完成登录、体检、导出、建议复核展示和卸载

## 勾选项
| 项目 | 结果 |
| --- | --- |
| 安装完成，目录正常创建 | |
| 桌面快捷方式存在 | |
| 开始菜单入口存在 | |
| 应用可正常启动 | |
| 启动后页面非空白 | |
| 登录页可打开 | |
| 首页体检入口可见 | |
| 输入授权目标后可开始体检 | |
| 结果页可正常展示，且能区分已验证 / 建议复核 | |
| PDF 可正常下载 | |
| PDF 中文显示正常 | |
| PDF 包含客户摘要、风险概览与建议复核项 | |
| 卸载可正常执行 | |
| 卸载后无残留入口 | |

## 快速判定
- 以上任一项未通过，即判定本轮验收不通过。
- 若启动后页面空白、黑屏或加载失败，判定不通过。
- 若 PDF 乱码、空白或缺少客户摘要 / 建议复核项，判定不通过。
- 若卸载后仍能看到入口或目录残留，判定不通过。

## 重点关注
- 启动后是否直接展示托管页面，而不是空白壳。
- 结果页是否能直接用于客户沟通，并明确建议复核项。
- PDF 是否能直接作为交付附件。
- 卸载是否彻底。

## 现场话术
- 先确认安装、启动、体检、PDF、卸载五步是否都能跑通。
- 再看页面是否非空白、PDF 是否具备客户摘要、风险判断和后续动作。
- 最后检查卸载后是否无残留入口。
