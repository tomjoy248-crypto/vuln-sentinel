# Windows 实机验收清单

## 目标
用于在 Windows 上验证 Vuln Sentinel 桌面版是否可以正式交付。

## 验收前提
- 已下载安装包 `artifacts/windows/Vuln Sentinel Setup.exe`
- 目标机器为普通 Windows 用户权限
- 具备一个可授权扫描的目标地址
- 已准备一份可导出的扫描结果数据

## 验收步骤
1. 双击安装包完成安装。
2. 确认安装目录创建成功。
3. 确认桌面快捷方式可见。
4. 确认开始菜单入口可见。
5. 启动应用，确认登录页可打开。
6. 进入首页，确认体检入口可见。
7. 输入授权目标并开始体检。
8. 确认结果页可以正常展示评分、证据、建议和工单入口。
9. 导出 PDF 报告，确认文件可下载且中文显示正常。
10. 打开 PDF，确认客户摘要、风险概览、发现项和建议都可读。
11. 执行卸载，确认应用被移除。
12. 确认桌面快捷方式与开始菜单入口一并被清理。
13. 重新点击入口，确认不会残留异常启动项。

## 验收判定
- 安装、启动、扫描、报告导出、卸载全部正常
- PDF 中文显示正常，无明显乱码或黑块
- 卸载后不残留可见入口
- 扫描结果页能直接用于客户沟通和交付

## 备注
如需要进一步验证真实交付，可补充：
- 多次安装/卸载循环
- 不同用户权限下的启动验证
- 断网后启动与恢复验证
- 大体量 PDF 导出验证
