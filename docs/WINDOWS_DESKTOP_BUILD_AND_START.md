# Windows 桌面壳打包说明

## 启动目标
- 默认打开 `Vuln Sentinel`。
- 默认进入 Web 首页。
- 保持登录、扫描、结果、套餐、审计入口一致。
- 页面文案统一为“建议复核 / 已验证 / 待人工复核”的交付口径。

## 打包目标
- 先打通 `cargo check`。
- 再打通 `cargo tauri build`。
- 最后生成 Windows 安装包（NSIS，当前用户安装）。

## 图标与品牌
- 图标放在 `src-tauri/icons/`。
- Windows 下使用 `icon.ico`。
- macOS 下使用 `icon.icns`。
- Linux / Windows 通用图标使用 `png`。
- 页面标题、入口文案和品牌名保持一致，避免出现混用。

## 交付注意
- 桌面壳只负责承载 Web 版。
- 核心业务逻辑仍由现有后端与前端提供。
- Windows 版发布前要确认 Build Tools、WebView2 和签名流程。
- 对 WAF、CDN、软 404、强登录态、重定向等场景，结果页应继续保留建议复核提示。

## 安装
- 安装后从开始菜单或桌面快捷方式打开。
- 移除可在 Windows 设置的应用列表中完成，保留的本地数据可按需清理。
- 首次启动若后端未运行，会提示先启动服务或切换到本地演示模式。
- 如果页面停留在启动态，应优先检查后端路径、端口占用和防火墙。
