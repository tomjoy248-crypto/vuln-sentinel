# Vuln Sentinel 桌面壳启动说明

## 默认启动体验

- 窗口标题：`Vuln Sentinel - 安全扫描与交付平台`
- 启动后优先打开本地 `http://127.0.0.1:8000/`，本地服务不可用时回退到托管 Web 版
- 适合需要 Windows 本地使用、同时保留在线兜底的场景

## 打包说明

- `src-tauri/` 负责 Rust 与桌面壳打包配置
- 前端由 `frontend/` 构建后同步到桌面壳或静态托管站点
- 当前 Windows 发布包采用 `NSIS`，不是 `MSI`

## 验收建议

- 启动后确认页面不是空白
- 确认登录、扫描、结果、工单和审计入口可用
- 确认本地服务或托管站点与发布包使用的是同一版本前端
